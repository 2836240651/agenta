## 2. 测试环境

- Windows 10+  
- 本地 Server `34206` + Web `5173` + Agent `wails dev`  
- PostgreSQL 可用；AI 生图 / Onebound 配置与现网开发环境一致  
- 1688 测试店铺 + 妙手账号（发布用例需要）  
- 至少 1 条可访问的同行商品链接（含主图+副图）

## 3. 分层

| 层 | 说明 |
|----|------|
| L1 | 单测 / mock：URL 解析、枚举、编排分支、表写入 |
| L2 | 联调：真实 Onebound + AI 生图，可不发妙手 |
| L3 | 端到端：含 Agent 妙手发布（或降级码签署） |

---

## 4. 用例清单

### 4.1 采集（L1/L2）

#### TC-COLLECT-001 合法链接采集成功

- **步骤**：提交合法 `peer_url`  
- **预期**：`source_images.length >= 1`；状态进入图优；错误码空  

#### TC-COLLECT-002 非法链接

- **步骤**：提交乱码 URL  
- **预期**：failed + `LISTING_1688_INVALID_PEER_URL`；不调用 AI 生图  

#### TC-COLLECT-003 无图商品

- **步骤**：mock / 选用无图详情  
- **预期**：failed + `LISTING_1688_COLLECT_NO_IMAGE`  

#### TC-COLLECT-004 采集上游失败

- **步骤**：mock Onebound 错误  
- **预期**：failed + `LISTING_1688_COLLECT_FAILED`  

---

### 4.2 图优（L1/L2）

#### TC-IMG-001 全量图优成功

- **步骤**：采集 1 主图 + N 副图（N≤上限）  
- **预期**：`optimized_images` 条数与源一致（或按产品约定）；URL 均 http(s)；任务继续发布  

#### TC-IMG-002 部分失败整单失败

- **步骤**：mock 第 2 张 AI 生图失败  
- **预期**：failed + `LISTING_1688_IMG2IMG_PARTIAL_FAIL`；不调用 Agent 发布  

#### TC-IMG-003 全部失败

- **预期**：`LISTING_1688_IMG2IMG_FAILED`  

#### TC-IMG-004 关闭图优

- **步骤**：`enable_img2img=false`  
- **预期**：使用原图进入发布分支；审计表 `optimized_images` 可为空或等于源  

#### TC-IMG-005 副图超上限截断

- **步骤**：源图 > 配置上限  
- **预期**：只处理前 N 张；日志/message 可提示截断（不视为失败）  

---

### 4.3 发布（L3）

#### TC-PUB-001 妙手上架成功（H3 成立）

- **预期**：Agent success；妙手/1688 可见商品；审计 success  

#### TC-PUB-002 发布失败

- **预期**：`LISTING_1688_PUBLISH_FAILED`；优图仍保留在审计表  

#### TC-PUB-003 发布未实现降级

- **预期**：`LISTING_1688_PUBLISH_UNSUPPORTED`；产品签署接受为 MVP 退出  

#### TC-PUB-004 Agent 离线

- **预期**：`LISTING_1688_AGENT_OFFLINE`  

---

### 4.4 Web（L2）

#### TC-WEB-001 1688 页可见链接输入

- **步骤**：打开 `/1688-auto-upload`  
- **预期**：有链接输入与提交；TaskList 可用  

#### TC-WEB-002 错误码文案映射

- **步骤**：触发 COLLECT_NO_IMAGE  
- **预期**：UI 显示映射后的中文，不只显示裸错误栈  

#### TC-WEB-003 Temu 页无 1688 输入

- **步骤**：打开 Temu 自动上架  
- **预期**：无同行链接控件；布局与改前一致  

---

### 4.5 隔离与回归（R）

#### TC-REG-001 Temu 上架冒烟

- **步骤**：按现网最小 Excel/流程跑 1 单（或项目既有冒烟脚本）  
- **预期**：成功或与改前相同基线；无新增 1688 枚举污染  

#### TC-REG-002 速卖通上架冒烟

- **预期**：同上  

#### TC-REG-003 Ozon 分支（若环境有）

- **预期**：比例/五场景逻辑未变
