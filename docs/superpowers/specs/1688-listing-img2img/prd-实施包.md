## 4. 用户场景

### 场景 A：单链接图优上架（主路径）

运营打开 1688 自动上架 → 选 Agent → 粘贴同行链接 → 提交。  
系统采集图片 → 图生图 → 下发 Agent → 妙手上架。任务列表显示成功。

### 场景 B：图优成功但发布未通（联调失败，非 MVP 退出）

图优完成并写入审计表；若妙手 1688 接口未就绪返回 `LISTING_1688_PUBLISH_UNSUPPORTED`。  
**产品已确认：MVP 必须打通妙手 1688 导入**——本场景只允许出现在联调中途，不得作为签署完成口径。

### 场景 C：采集失败

无效链接或无图 → 任务 failed + `LISTING_1688_COLLECT_*`，不调用生图、不下发 Agent。

### 场景 D：图优部分失败

与现网产品发布一致：整单失败 + `LISTING_1688_IMG2IMG_PARTIAL_FAIL`，不混用原图上架。

### 场景 E：其它平台无感

Temu / AE 用户操作路径与结果与改前一致。

## 6. 里程碑

| 里程碑 | 交付 | 退出标准 |
|--------|------|----------|
| M1 采集 | Onebound 拉图 + 单测 | 真实链接出图列表 |

| M3 Web | 1688 输入区 + 错误映射 | 运营可提交并看到状态 |
| M4 发布 | AlibabaFactory **妙手 1688 导入** | 端到端上架成功（非 UNSUPPORTED） |
| M5 回归 | Temu/AE 冒烟 | 门闸全绿后可合并 |

建议顺序：M1 → M2 → M3 → M4 → M5（M3 可与 M2 并行）。
