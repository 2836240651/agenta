# 测试用例：1688 竞品向导上架（Wizard v2）

**日期**：2026-07-23  
**对齐**：[README](./README.md) · [需求 AC](./requirements.md)

说明：用例 ID 前缀 `TC-S` 会话 · `TC-C` 采集 · `TC-I` 图优 · `TC-P` 发品 · `TC-R` 回归 · `TC-X` 安全/隔离。

---

## 1. Step1 采集会话（TC-S）

| ID | 步骤 | 期望 |
|----|------|------|
| TC-S-01 | 选在线 Agent → 打开登录 | Agent 打开 1688 登录页 |
| TC-S-02 | 登录后点「我已登录」 | Cookie 加密落库；探针 `code==0`；可进 Step2 |
| TC-S-03 | 未登录点确认 | 探针失败；停留 Step1；有错误码 |
| TC-S-04 | Cookie 过期后再校验 | `SESSION_INVALID`；可重开登录 |
| TC-S-05 | Agent 离线 | `AGENT_OFFLINE` |

---

## 2. Step2 采集（TC-C）

| ID | 步骤 | 期望 |
|----|------|------|
| TC-C-01 | 合法 offer 链接 → 分析 | 标题+≥1 图+SKU 预览 |
| TC-C-02 | 无效链接 | 解析失败枚举；不可进图优 |
| TC-C-03 | 遇验证码 | 提示人工过码；完成后重试成功 |
| TC-C-04 | 采集会话失效中途 | 引导回 Step1 |
| TC-C-05 | 解析字段与 1688- 样例对齐 | 关键字段一致（移植验收） |

---

## 3. Step3 图优（TC-I）

| ID | 步骤 | 期望 |
|----|------|------|
| TC-I-01 | Slot0 生成 | 调 listing1688 images API；出结果图 |
| TC-I-02 | 改 prompt 重生成 | 仅该 Slot 更新 |
| TC-I-03 | 沿用原图 | 不调 hyhacct；状态可选定 |
| TC-I-04 | 未全选定点下一步 | 被拒；`IMAGES_NOT_READY` |
| TC-I-05 | 副图加到第 10 张 | 拒绝；上限 9 |
| TC-I-06 | 抓包确认上游 | 经 Server → `AiEditImage` → hyhacct；无直调 produce_images |

---

## 4. Step4 商家发品（TC-P）— M3

| ID | 步骤 | 期望 |
|----|------|------|
| TC-P-01 | 商家已登录 + 全选定 → 发布 | 商品在**自家 1688 商家后台**可见 |
| TC-P-02 | 商家未登录 | `SELLER_SESSION_INVALID`；引导登录商家中心 |
| TC-P-03 | 发品页失败 | `PUBLISH_FAILED`；可重试 |
| TC-P-04 | 审计调用链 | **无** ProductIssue / 妙手 / 店小秘发 1688 |
| TC-P-05 | 采集已登录但商家未登录 | 不得静默用采集 Cookie「冒充」发品成功 |

---

## 5. 回归与隔离（TC-R / TC-X）

| ID | 步骤 | 期望 |
|----|------|------|
| TC-R-01 | Temu 列表/上架冒烟 | 无本向导控件；原流程可用 |
| TC-R-02 | AE 相关冒烟 | 无回归 |
| TC-R-03 | v1 `/1688-auto-upload/listing` | 仍可用（与向导隔离） |
| TC-X-01 | 前端 Network | 无 Cookie 明文 |
| TC-X-02 | 日志抽样 | Cookie 脱敏 |
| TC-X-03 | API 前缀 | 向导只打 `/listing1688/*`；不误打 v1 妙手发品 |
