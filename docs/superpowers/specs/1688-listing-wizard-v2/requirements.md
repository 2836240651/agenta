## 1. 问题

- 要审核竞品、逐张调图后再发到**自家 1688 商家店**  
- 竞品采集已在 `D:\reverselab\1688-` 跑通，需接入 Commander

## 2. 术语

| 术语 | 含义 |
|------|------|
| 采集会话 | 打开 1688 详情/生意参谋用的登录态（多为买家或通用） |
| 商家会话 | 1688 **商家中心 / 发品页**登录态 |
| Workflow | 一次向导（登录→采集→图优→商家发品） |
| Slot | 主图 + 副图≤9 |
| hyhacct | 图生图上游 |

## 3. 假设

| ID | 假设 | 验证 |
|----|------|------|
| H1 | Agent 可维护采集 Cookie 并探针校验 | TC-S-* |
| H2 | 移植 1688- 解析可得标题/图/SKU | TC-C-* |

---

## 4. 范围

### 做（MVP）

1. Step1 采集登录 + Cookie 加密校验  
2. Step2 单链接 CDP 采集预览（解析自 1688-）  
3. Step3 逐张图优（hyhacct）  
4. Step4 发布到**自家 1688 商家后台**（浏览器自动化）  
5. 错误枚举 + 平台隔离  

### 不做

- 妙手/店小秘发 1688 商家店  
- 场景 B（铺淘宝/抖店/跨境等）  
- 自动过码、批量链接、Prompt 模板中心  
- 从零重写采集  

### P1

- Onebound 降级（须标注，不计入主验收）  
- 商家多店切换细则  
- 官方商家版 ERP 替代浏览器发品（若立项）

## 5. 用户故事

| ID | 故事 |
|----|------|
| US-01 | 选 Agent → 登录 1688 → 提示采集会话有效 |

## 6. 验收（AC）

| ID | 标准 |
|----|------|
| AC-01 | 采集登录+校验成功可进 Step2 |
| AC-02 | CDP 采集含标题+≥1 图+SKU |
| AC-03 | 单 Slot 图优/重生成/沿用原图可用；未全选定不可发品 |
| AC-04 | 端到端：图优结果发布到**自家 1688 商家后台**可见 |
| AC-05 | 失败返回枚举码+中文 |
| AC-06 | Temu/AE 冒烟无回归 |
| AC-07 | v1 `/listing` 仍可用 |
| AC-08 | 前端/日志无 Cookie 明文 |
